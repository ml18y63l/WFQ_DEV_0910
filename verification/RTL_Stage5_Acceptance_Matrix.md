# FAST5 第五阶段功能验收矩阵

基线：`Design_Spec_V1.2.md` §14。实现语言：Verilog-2001。范围：ISSUE_INTERVAL=5，默认 10/1024 及较宽指针 11/1024，另含规定的参数展开/运行检查。

本矩阵给出测试与要求的对应关系；整轮状态、实际随机规模及统计以 `RTL_Stage5_Report.md` 和 `build/stage5/results.json` 为准。F25 需要未实现的 PIPE6；F30 按用户要求暂不执行。不得把它们计为 PASS。

## 2. 随机规模与覆盖编码

`long_random` 以接受计数结束，默认每种 1024 槽配置运行 10 个独立种子，每个至少接受 100,000 次随机操作。计数不包含后续完成已保持请求和排空产生的操作。末尾必须满足 accepts=commits=2×responses，队列/响应/预留/上下文全部清空，全部地址归还 FREE。

随机流包含均匀、热点、同值、递增、递减、0/4095 极值交错、少量前缀和分散前缀，共八种分布；同时变化请求比例、间隙、响应背压、两代/第三代请求。源协议检查器保证 valid 等待接受时不撤销或改变插入字段。每个种子与运行参数记录在独立日志及结果文件中。

`build/stage5/coverage.csv` 保存完整联合元组及命中次数，不只保存各维度总数。每个提交记录以下接受/提交语义：

| 位段 | 字段 | 编码 |
| :--- | :--- | :--- |
| 0 | insert | 0=出队，1=插入 |
| 2:1 | occupancy | 0=普通，1=空，2=无可分配地址 |
| 3 | duplicate | 插入时已有同键；出队时还有其他同键节点 |
| 6:4 | path | 0=无前驱，1=A，2=B，3=C，4=出队不搜索 |
| 8:7 | bank_role | 0=base，1=下一代，2=空队列建立首代 |
| 10:9 | clear_level | 0=无删除 marker，1=只清叶 bit，2=连带清父 bit，3=连带清根 bit |
| 12:11 | position | 0=空队列插入，1=头，2=中间，3=尾；出队为头 |
| 14:13 | response_credit_used | 接受沿前已占用响应项+预留，取 0/1/2 |
| 16:15 | previous_insert | 上次接受为 0=出队、1=插入；2=首个请求无前项 |
| 17 | next_raw | 本次出队 E0 是否与旧插入的 NEXT 修补同址 |

配置作为 CSV 的额外维度。runner 对默认与较宽配置检查每个必需单维度均命中，并对 F26 的全部 28 个连续操作模式设置独立通过条件。联合元组保留实际可达组合，不将全部笛卡尔积当作覆盖率分母：例如空队列出队、满响应信用出队、出队走 A/B/C、无前驱而发生前驱 NEXT RAW，均非合法可接受组合。

## 3. 逐沿不变量与检查边界

参考模型只以真实握手和接受的绝对周期驱动。所有操作的固定提交、修补、写回完成时刻都独立推导。每次提交遍历完整 live 有序数组，对比 DATA、应用 pending 后的 NEXT、接受序号关联、head/cache、各 bank 边界/计数。

RC/TT/L3 核对改变键的结果和精确写地址/条件；没有提交的周期禁止 metadata 写。L1/L2 在每次提交后完整比较。每 257 次提交及各定向排空执行 TT/RC/L3 全表扫描和 FREE/live/预留全量分区扫描。FREE 每次读写的地址及数据另有逐沿检查，参考 owner 状态在每次分配/提交/释放时检查合法转换。这些检查共同覆盖存储状态及容量归属，不要求在硬件内加入扫描逻辑。

所有 RAM 读使能、阶段及地址均以参考队列推导，特别检查 E0 精确叶与 E1 唯一备用叶；L3 读写互斥。DATA/NEXT/FREE 写沿/地址/内容逐沿核对。NEXT E5 物理修补落入 RAM 后仍检查 pending 延续至 E6，旧写回完成与新出队提交同沿分别更新上下文。

小容量 16/32 另外执行每配置 256 条四操作轨迹的有界穷举仿真。每条从四节点状态开始，操作字母表为 insert(0)、insert(15)、insert(4095)、extract；穷举全部 4^4 组合，并完整排空。它证明的是该有限测试域的仿真结果，**不是对任意输入和任意内部状态的形式证明**。当前环境没有运行形式验证工具。

参数 11/2048、12/4096、16/65536 的顶层运行包含完整初始化、最大物理指针、两 bank、不同键/同键及排空；最大配置不做 65,536 项全容量长随机。最大容量 FREE 全分配/回收和初始化边界另外由第一/第三阶段组件完整回归覆盖。
