### 3.2 新增内容未发现功能性漏洞

本轮对修订引入的新攻击面逐项核查，均通过：

1. **栈索引缩窄**：free_count 满值 1024 截成地址 0 的风险——§6.5 明确“先在 COUNT_WIDTH 或更宽临时值上检查 <MEM_DEPTH 再转 ADDR_WIDTH、free_count=0 不得减一读取、出队写栈须沿前 free_count<MEM_DEPTH”；且准入门控（free_count>0 / queue_level>0）与资源不变量使正常路径索引恒界。计数/索引损坏归 code=5，指针编码越界归 code=7，分层清晰、无重叠无空洞。
2. **指针编码**：默认 1024 个编码全部合法、不以牺牲地址 0/1023 作 NULL 哨兵（NULL=valid:0）；11/1024 配置的 1024～2047 在不截断高位的前提下拒绝，不会别名到 0～1023；NULL.ptr 不参与检查/寻址。
3. **检测点覆盖**：插入 E1 的 FREE q、E_P 的 TT q/跨代尾、出队 E0 的缓存地址、E1 的下一头 next、最终节点写地址（§13.2），加上 §6.5“FREE 写入的被释放 head.ptr 先检查范围”与 §10.3 新增段落——插入/出队全部指针消费点均有归属检查；出队头指针 h.ptr 有“E1 释放前检查 + 再分配时 E1 复查”双重覆盖。
4. **metadata 与节点地址分离**：TT/RC 保持 8192×13-bit 地址、L3 保持 512，tag=4095 恒为合法标签；F34 与模型 RC[8191] 实测一致，节点容量缩窄不侵入 metadata 地址域。
5. **初始化**：INIT_WRITES=max(8192,1024)=8192 由 metadata 主导，R8191/R8192/R8193 不变；扫描计数器显式要求由 INIT_WRITES 派生（需 ≥14 bit 表示 8192），排除了误用 COUNT_WIDTH/ADDR_WIDTH 扫描的陷阱（附录 B.21 呼应）。
6. **容量无关性**：§11.5 新增声明正确——指针释放/重分配先后关系只依赖发射间隔与写回完成沿，与深度、位宽无关；两上下文结论在 1024 槽下不变。
7. **F04 第 1025 项语义**：满容量由 free_count==0 准入背压（非 fault）；fault 1 仅在 old_RC>=1024（状态损坏）时触发。口径正确。
8. **术语迁移完整性**：全文扫描无“退休/E_R/retire”残留；E_WB=I+1、E2=2 周期不变；“写回完成与最后一次物理写分别计时（E_I vs E_WB、E1 vs E2）”的定义与仓库 CLAUDE.md 的生命周期指令一致。

## 4. 实现障碍确认与排序

### O-7（新增）Verilog-2001 扁平化的布局与约定归属

禁用 struct/typedef 后，§11.1 所列事务描述符（payload、n/p/successor、旧值快照、各写目的/enable/data、head/cache/bank 变化、响应预留身份）与 pending overlay、两上下文记录都必须变成定宽扁平向量加手工切片。目前：

1. 规格只固定了 link（11 bit）和 payload（37 bit）的打包（§2.3），事务描述符/overlay 的字段布局**无统一定义**，归属为“实现者自定”；字段偏移失配是一类新的编码错误面（附录 B 尚无对应条目）。
2. F24 要求 testbench 层次化读写/force 注入、覆盖率提取依赖**稳定的信号命名与层次路径**，布局漂移会使注入点失效。
3. `.vh` 公共包含文件只约定了存在性：`wfq_clog2` 常量函数在 V2001 中无法跨模块共享，只能在每个使用模块内定义或经 .vh 文本包含（等价复制），最小内容集未约定。

**建议**：在 §15.1 或附录 B 增加一条——实现者在模块头注释（或独立 README）固定描述符字段布局/命名并纳入代码评审；明确 .vh 的最小内容（如局部参数名、`wfq_clog2` 函数体、字段偏移 localparam）。不阻碍启动，但应在编码开始前定下。

### O-1～O-6 延续状态

- **O-1（出队 E0→E1）与 O-2（插入 E_C 末级）**：仍是决定成败的两条单拍路径，PIPE6 不缓解（§10.3/§15.3 原样保留）。V1.2 的指针范围防护在默认配置下对已定宽指针恒真、可被综合折叠为零逻辑，**不加重**这两条路径；较宽配置在 E1/E_P/E_C 检查点新增的比较器已列入 §15.2 新行，属小增量。
- **O-3（E0 输入直达路径）**：新增 free_count-1 的 11-bit 减法与检查后缩窄（§6.5），量级可忽略，仍按原 input delay/门控约束处理。
- **O-4（FAST5 前视网络）**：不变；L1/L2 状态位与 V1.1 相同（544 bit）。
- **O-5（写侧流水宏禁令）**：未落规（见 R-1）。
- **O-6（同沿写回完成/新提交的上下文控制器）**：更名后语义不变（§10.4“必须支持同沿释放旧上下文并接收新提交描述符”），要求照旧。

## 5. 本轮独立复核通过项

1. **参数/位宽契约**：7 组合法（10/1024、11/1024、11/2048→COUNT=12、12/4096、4/16、5/16 宽指针、16/65536）与 8 组非法全部复核；模型 `widths()` 的 `(depth-1).bit_length()`/`depth.bit_length()` 与 clog2(MEM_DEPTH)/clog2(MEM_DEPTH+1) 逐组等价。✓
2. **资源数值复算**：L3 8,192 + TT 90,112 + RC 90,112 + DATA 37,888 + NEXT 11,264 + FREE 10,240 = 247,808 bit（恰 30.25 KiB）；加 L1/L2 544 = 248,352 bit ≈ 30.32 KiB；较 V1.1 减 227,328 bit = 27.75 KiB = 47.79%。与 §6.2/§1.4 逐项一致。✓
3. **编码穷举**：默认 10-bit 1024/1024 全合法且覆盖全部节点地址；11/1024 的 2048 种编码 1024 拒绝、无截断别名（模型显式验证了“先丢 bit 10 会命中活地址”这一反例）。✓
4. **排程不变性**：`verify_ports` 复用通过 56 组；§10.2/10.3/10.4 逐沿表与 V1.1 逐项相同（仅 E_R→E_WB 改名）；提交沿互斥、快照有效性、两上下文证明全部延续（引擎未改，仅加防护）。✓
5. **Verilog-2001 骨架合法性**：非 ANSI 端口 + 模块内常量函数 + localparam 派生端口位宽与所引 UG901 常量函数示例同型（常量函数先于 localparam、localparam 先于引用它的端口声明）；`parameter integer` 于 1364-2001 参数端口列表合法；`+:`/`-:` 为 V2001 特性；§15.1 禁用清单与全文代码块核对无 SV 残留。尚未实际编译，spec 亦如实声明“当前没有实际 Verilog 编译或综合结果”。✓
6. **术语一致性**：§2.2/§4.4/§5.2/§5.3/§6.4/§10.1～10.4/§11.3/11.5/§14.2/§14.5/附录 A/B 的 E_WB 语义与周期数值一致，无旧记号残留。✓
7. **初始化契约**：R8191/R8192/R8193 与 8193 周期预算（32.772 μs@250 MHz）不变；FREE 只写 i=0～1023、值为零扩展地址。✓
8. **F31～F34 与模型对应**：F31↔`allocated==set(range(1024))` 全覆盖断言；F32↔编码契约 + “不得向 10-bit 字段赋 1024 伪注入”警示（与 §2.4 末段呼应，预防了一类验证假阳性/假阴性）；F33↔7+8 组合；F34↔两代容量/重用场景与 tag 0/1023/1024/2047/4095 激励、RC[8191] 检查。✓
9. **模型保真度（逐行审查）**：`BoundedEngine` 对每次读/写/发布做地址深度防护（metadata 8192/512 与节点 1024 分表——F34 的“metadata 地址不按节点地址截断”在每次访问上强制）；TT/NEXT/FREE 写值、head/tail、cache next、bank 头尾全部经 `node_address` 指针域检查；每沿校验 free_count/reserved/level < 2^count_width（11-bit 计数不回绕）与全部写值。✓
10. **新场景有效性**：两代 512/512 交错填满共享 1024 → 第三代阻塞断言（can_insert(base+2) 为假、base+1 为真）→ 排空旧 bank 推进 base → bank 重用后 full 结构检查通过（8192 项 RC/TT 全比，无 metadata 污染）；同键 1024 填满/排空 RC[8191] 0↔1024、满时不接受。✓
11. **附录 C 数字与实测一致**：含 FAST5 11,024/46 RAW、PIPE6 11,028/39 RAW、3072 次两代场景等全部条目。✓
12. **CLAUDE.md 与 V1.2 一致**：运行命令、位宽/编码描述、fault 5/7 分工、F01～F34、冻结项摘要均与正文吻合。✓

## 7. 结论与放行建议

V1.2 的容量/位宽解耦、Verilog-2001 约束、写回完成术语和越界防护分层在规格层面自洽：排程与生命周期证明未被容量缩小触动且已声明容量无关；资源数值、参数合法性、编码契约经独立复算与模型双重印证；未发现会导致错误功能行为的新逻辑漏洞。

建议顺序：

1. **启动前落规（约半天）**：R-1 六项 + N-1；N-2 在附录 C 补一句“RR 仲裁与初始化序列未入模，由 F18/F01 承担”。
2. **先立 Verilog-2001 骨架**：端口/常量函数/localparam/time-0 参数检查（$display/$finish + 脚本非零退出）先过一次严格 V2001 模式编译与 lint，再展开功能逻辑；同时按 O-7 固定描述符字段布局、命名与 .vh 最小内容集。
3. **时序预算优先级不变**：O-1（出队 E1）与 O-2（插入 E_C 末级）仍是两条决定成败的单拍路径；O-3 写入 SDC；F30 双配置判据 f5 > (5/6)·f6 不变。默认配置的范围比较可折叠，不构成新瓶颈；较宽配置按 §15.2 新行计入。
4. **冻结项（§16.2）已更新**：容量/指针/地址/计数独立位宽与“冗余指针位不得改作 valid/哨兵”属编码契约，RTL 不得回退 12/4096 旧假设（附录 B.9/19/20/21 为对应检查点）。
5. **可选改进**：N-3 补跑一轮 `BoundedEngine(ii, 1024, ptr_width=11)` 周期模型，把 11/1024 的访问路径也纳入逐沿检查（附录 C 相应更新）。
